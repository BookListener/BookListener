# Brief: BookListener 主题设置子页 UI 美化方案

## 任务
为 BookListener（安卓本地音频播放器）的"主题"设置子页设计至少 3 套美化方案，产出示例图（手机设置页截图样式）。

## 页面结构（已定，不可改）
单页三区块，HorizontalDivider 分隔，自上而下：
1. **外观模式**：三态（白天/黑夜/自动），默认自动；切档走 AppCompatDelegate.setDefaultNightMode
2. **玻璃效果**：两开关（主页动作条玻璃 / 播放详情面板玻璃）
3. **语言**：三态（跟随系统/简体中文/English）

## 方案方向（3 套）
- **方案A · 分组卡片**：三区块各自成独立圆角卡片（surfaceContainer 卡片+描边），区块标题小字左对齐，三态用胶囊分段选择器，两开关右侧 Switch；卡片间留白，弱化分隔线
- **方案B · 玻璃拟态延续**：延续 App 的液态玻璃语言，三区块为毛玻璃面板（半透明+blur），三态用图标化胶囊按钮（含太阳/月亮/自动图标），高对比文字，动态色强调选中
- **方案C · 极简列表**：回归纯列表，区块标题用前置小图标+标题，三态用居中单选圆点+行内文字，分隔线细淡；极简留白，静态无卡片

## 界面文字（中文，须准确）
标题：主题
区块1：外观模式 / 白天 / 黑夜 / 自动
区块2：玻璃效果 / 主页动作条玻璃 / 播放详情面板玻璃
区块3：语言 / 跟随系统 / 简体中文 / English
顶部返回箭头；可选副标题文案。

## 画幅
手机竖版设置页截图，9:16 竖屏，深色/浅色各可选（沿用 App 配色）。

## 追加：方案A 体系延展（设置页其他项目统一分组卡片风格）
已选方案A（分组卡片：独立圆角卡片+细分隔线+胶囊分段选择器+Material3浅色留白）。
需将设置主页及其他子页按同一视觉语言重设计示例图：
- 设置主页：6 个入口（文件夹管理 / WebDAV账号 / 睡眠定时 / 缓存管理 / 主题 / 关于）按语义归为 2-3 组卡片。
- 子页示例（按方案A）：文件夹管理（列表+添加）、睡眠定时（三态）、缓存管理（配置+清理）。
