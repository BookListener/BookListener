# BookListener

Android 音频播放器，支持**本地文件夹、WebDAV**双源统一浏览与播放，适合听有声书和长音频：每个文件夹独立记住播放进度，杀后台再打开也能回到原来的位置。

## 功能

- **双源播放**
  - 本地：添加手机/平板上的音频文件夹，下次一键进入
  - WebDAV：连接 Nextcloud、群晖、自建 NAS 等支持 WebDAV 的服务
- **专辑化曲目**：自动解析并入库音频标签——专辑 / 作者 / 专辑作者 / 标题 / 音轨号 / 碟号 / 流派 / 年份 / 作曲 / 媒体类型 / 编码工具，按专辑分组展示；没有标签时用文件名排序，也能正常听
- **搜索**：顶部搜索框，可搜索专辑与曲目
- **系列分组**：主页专辑按系列名标签聚合分组，组头显示系列封面、可收展；组内按系列序号排序；单专辑系列折叠为普通专辑行；无系列标签的专辑保持普通行
- **CUE 整轨分轨**：自动解析 .cue 整轨为虚拟轨，逐音轨连续播放、进度精确到分轨；内容文件列表点击 .cue 可浏览其虚拟轨列表
- **m4b 有声书**
  - 支持 m4b 格式识别与入库，标题 / 作者 / 专辑 / 系列名 / 系列序号 / 封面自动解析
  - 章节自动分轨：每章生成一条虚拟轨，整本作为一个作品顺序连续播放，章节名缺失自动补「第 N 章」
  - 章节名可搜索，按章断点续听；内容文件列表仍忠实显示原始 .m4b 文件
- **播放体验**
  - 每个文件夹独立记住播放进度，切换文件夹不会自动开始播放
  - 播放速度 7 档：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 1.75x / 2.0x
  - 循环模式：顺序 / 单曲 / 列表
  - AB 段重复：设置起点终点反复听一段
  - 定时关闭：一次性定时（15/30/45/60 分钟）或全局设置
  - 锁屏/通知栏控制、后台播放、来电自动暂停
- **文件夹管理**：设置 → 文件夹管理：管理已添加的本地/网盘文件夹，进入目录浏览全部原始文件（含子文件夹、cue、整轨），非音频文件也忠实显示
- **主题与语言**：外观模式（白天 / 黑夜 / 自动）、玻璃效果开关、语言三态（跟随系统 / 中文 / 英文）
- **界面细节**
  - 正在播放的曲目高亮显示，进入专辑自动定位到当前条目
  - 超长文件名自动滚动展示，不截断信息
  - 专辑封面自动识别展示

## 安装

直接安装 APK（release 为正式包，debug 用于排障）。当前包名：`com.booklistener`。

> **注意**：包名发生过变更（旧包名为 `com.simple.musicplayer`）。从旧版升级需先卸载旧版，安装后已添加的文件夹、播放记录、网盘授权需要重新配置一次。

## 快速开始

1. **添加本地音乐**：进入「文件夹管理」→「添加播放文件夹」，选择存有音频的目录，之后在首页点击该文件夹即可播放
2. **配置 WebDAV**：在网盘后台开启 WebDAV 并生成应用密码，填入「设置 → 网盘 → WebDAV」

支持的音频格式：mp3 / m4a / **m4b** / flac / wav / ogg / aac 等常见格式。

## 常见问题

- **切换文件夹后会自动播放吗？** 不会。切换只切换播放记录，点播放后才开始。
- **杀后台后进度还在吗？** 在。每个文件夹的播放进度都会保存，重新打开会定位到正在播放的曲目。
- **歌曲显示的名字不对？** 优先使用音频标签（专辑/作者/标题），没有标签时用文件名，均可自然排序。

## 已知限制

- 暂不支持百度网盘 / 天翼云盘 / 移动云盘（需要额外适配）
- WebDAV 仅支持标准实现，个别私有服务可能不兼容
