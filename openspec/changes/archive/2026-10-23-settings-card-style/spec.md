# Spec

## 背景

设置页当前为单列平铺 + HorizontalDivider 列表，主页 6 入口与子页控件样式零散。用户选定「方案A·分组卡片」并借鉴豆包侧边栏极简线性图标，要求：主页按语义分组卡片、三元选择器统一为「图标+文字+主题色下划线」、图标统一极简线性风格。

## 范围

仅改动设置页 UI 外观与控件样式，不涉及任何业务逻辑、播放、扫描、数据库。

## 1. 主页分组卡片

主页 6 个入口按语义归为 3 组卡片：

| 组名 | 入口 |
|---|---|
| 资料源 | 文件夹管理、WebDAV账号 |
| 播放与外观 | 睡眠定时、主题、缓存管理 |
| 关于 | 关于 |

每组用 surfaceContainer 圆角卡片承载，卡片间留白。入口行结构保持：左侧线性图标 + 主文字 + 副说明 + 右箭头；组标题为分区标题（小号、onSurfaceVariant）。

## 2. 三元选择器组件

新增可复用组件 `SettingsTriSelector`：

- 三个选项横向均匀分布，每项 = 图标（上方）+ 文字（下方）
- 选中项：主题色图标 + 主题色文字 + 细短下划线
- 未选中项：深灰文字/图标
- 无卡片、纯底

用于：

- **外观模式**：白天（太阳）/黑夜（月亮）/自动（循环）
- 当前外观模式用 RadioButton 纵向列表，改为该组件横向三态

## 3. 图标

AppIcons 新增（Material 官方 24x24 线性 path）：

- `Sun`（白天）→ light_mode
- `Moon`（黑夜）→ dark_mode
- `AutoLoop`（自动）→ sync 或 brightness_auto

主页入口沿用现有 Folder/Cloud/Timer/Palette/Storage/Info。

## 4. 结构约定（沿用既有规范）

- 子页：返回箭头 + titleMedium 标题 + bodySmall 说明 + 配置项
- 主页：仅列举配置项（图标+文字+右箭头），不放开关

## 验收

1. 主页按 3 组卡片展示 6 入口，行为不变
2. 外观模式三态为横向图标选择器，选中项主题色+下划线，点击切换正确
3. AppIcons 新增 3 图标且编译通过
4. 现有 UT 全绿
