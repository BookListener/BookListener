# 系列聚合采用专辑列表内联分组（不设独立系列页/视图）

Status: accepted

v2.2.0 标签解析将 series/seriesNumber 入库后，需要按系列名聚合专辑并按系列序号排序。曾考虑三个形态：独立「系列」视图（主页分段切换）、替换专辑聚合为主维度、专辑列表内联分组。最终定为**内联分组**：在主页专辑列表的「最近播放/尚未播放」两分区内，有系列的专辑聚为「系列分组头 + 组内专辑行」，无系列专辑保持普通行；只含 1 张专辑的系列折叠为普通专辑行（副标题显示系列名）。

理由：播放与搜索只和专辑/作品相关（SPECS 第一节），系列是纯浏览维度，不值得开辟第二导航层级；单专辑系列若也成组会产生无意义的多一层导航。折叠规则与内联分组一体：分组头只在能容纳 ≥2 张专辑时出现。
